Cobertura Porto Seguro

Brasília, DF

Cobertura coletiva projetada para reunir moradores sem criar obrigação de convivência.

← Projetos
Categoria Espaços Coletivos Local Asa Sul, Brasília Área 130m²
Atmosfera

A cobertura coletiva tinha espaço e potencial que não se traduziam em uso. A reforma partiu da academia e chegou até o gourmet, transformando ambientes subutilizados em destino real para os moradores.

O desafio

Criar uma área coletiva capaz de funcionar tanto para o uso cotidiano quanto para eventos maiores, sem que um modo comprometesse a lógica do outro.

A solução

Reorganização completa da cobertura com área gourmet projetada para convivência, academia reformada e circulação clara entre todos os ambientes.

No detalhe

Cada área foi pensada para funcionar de forma independente e criar continuidade natural quando os espaços se abrem para ocasiões maiores.
