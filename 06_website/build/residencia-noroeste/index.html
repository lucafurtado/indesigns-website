RESIDENCIAL

Cobertura Duplex Noroeste

Projeto de interiores para uma família que mudou de escala sem querer abrir mão do que funciona.

← Projetos
Categoria Residencial Local Noroeste, Brasília Área 220m²
Atmosfera

Uma família acostumada a um ritmo de morar que a nova planta ainda não tinha. O projeto trabalhou a partir dos hábitos de cada um, transformando 220 metros em um apartamento que parece construído do avesso para dentro.

O desafio

Trazer para um apartamento novo a identidade e a rotina de uma família acostumada a outro ritmo de morar, sem que o resultado parecesse uma adaptação.

A solução

Marcenaria planejada a partir dos hábitos de cada membro da família, com armazenamento integrado e escolhas que criam coesão sem apagar o que já existia.

No detalhe

A mesa de estudos das crianças foi projetada para crescer com elas, sem precisar ser trocada conforme as fases mudam.
